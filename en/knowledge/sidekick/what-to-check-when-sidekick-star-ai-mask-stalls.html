What to Check When Sidekick Star's AI Mask Generation Won't Finish

Sidekick Star's AI mask generation can appear to stall without ever completing. Here is what is actually happening, what you can try, and the improvements made on the development side.

SideKick Beginner-friendly Updated: 2026-09-03

Ichiro Murata · Photographer / SideKick Developer

Sidekick Star can detect the sky or the subject automatically and build a mask from it. Very occasionally, that process appears to stall without ever signalling that it has finished. Here is what is going on, and what you can actually try.

What is happening

AI mask generation works by launching the work as a background process, separate from Photoshop itself, and then picking up the result once it completes.

If that background process fails to start properly, Photoshop can keep treating the job as still running and wait indefinitely for a completion that never arrives. What makes this hard to recognise is that the job is not slow because it is heavy: in some cases it stumbles at startup and never gets going at all.

What to try first

When processing appears to have stalled, check the following.

  • Wait a little, then try again: if you have just processed a large batch of photos in one go, the processing engine is known to become temporarily unstable immediately afterwards. Waiting a few minutes and running it again will sometimes complete without any trouble.
  • Update Sidekick Star to the latest version: the reliability of the startup process is reviewed on an ongoing basis. Staying on an older version means you may run into a problem that has already been resolved.
  • Check Task Manager to see whether the background process is running: this gives you a way to tell whether processing has genuinely stopped or is simply taking a long time.

Improvements made on the development side

Investigating this meant suspecting several causes and finding, one after another, that each was not it. What is understood now is that the processing engine tends to become temporarily unstable immediately after a long run of file operations.

With that in mind, a mechanism was built in that retries automatically, leaving an interval between attempts, when startup fails. Processing has been confirmed to run through to completion on real data of a substantial number of frames.

That said, startup failures themselves have not been eliminated. What has changed is that when one happens, recovery is more reliable.

If that still does not solve it

If none of the above improves things, please get in touch and include the circumstances in which it occurred: how many images you were processing, what you had been doing immediately beforehand, your Photoshop version, and so on. Information about the environment where it actually happened is what helps pin down the cause.

Summary

When AI mask generation appears to stall, the cause is usually that the background process did not start properly. Try waiting and running it again, or updating to the latest version, and see how things go; if it keeps happening, get in touch with the details. The machinery behind this kind of automated processing behaves differently depending on the number of photos and the environment, so it is reviewed on an ongoing basis, based on how it behaves in real use.
