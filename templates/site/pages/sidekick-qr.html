Sidekick QR ｜ by Sidekick Lab

Sidekick QR 写真から、Webへつなぐ。

写真と、見てほしい Web ページの URL。 その2つから、QRコード付きの「カード」画像を1枚作るツールです。 カードの QR をスマートフォンで読み取ると、その Web ページが開きます。

ダウンロード（Windows・無料） 使い方を見る

Version 1.0.0 ・ ZIP（約 25 KB）・ インストール不要

What it does

写真 ＋ URL → QRカード

写真の横に QRコードとタイトル・説明を並べた画像を作ります。 写真はトリミングせず、全体が収まるように配置します。

🖼️

写真を選ぶ

JPEG / PNG の写真に対応します。カメラやスマートフォンで撮った縦位置の写真も、正しい向きで使えます。

🔗

URL を入れる

ポートフォリオ、ブログ記事、作品ページなど、任意の Web ページの URL（http / https）を QRコードにします。

💾

確かめて、保存する

できあがったカードをプレビューで確かめてから、PNG 画像で保存します。保存されるのは、プレビューで見ていた画像そのものです。

How it works

使い方

写真を選ぶ

カードにしたい写真（JPEG / PNG）を1枚選びます。

URL・タイトル・説明を入れる

QRコードにする Web ページの URL と、カードに載せるタイトル・説明文を入れます。

カードを作って保存

プレビューを確かめて PNG で保存します。スマートフォンで QR を読み取ると、指定したページが開きます。

Local only

写真は、どこにも送らない。

写真・入力した URL・作ったカードは、Sidekick QR の処理のために外部のサーバーへ送信されません。 カードは手元のパソコンの中で作ります。写真をアップロードする必要も、アカウントを作る必要もありません。

QRコードもパソコンの中で作るので、入れた URL が外部の QR 作成サービスに渡ることもありません。 なお、カードの QRコードを読み取ったスマートフォンは、その QRコードが指す Web ページにアクセスします。

Spec

動作環境と仕様

Windows 向けの正式版です。

バージョン 1.0.0
動作環境 Windows（Microsoft Edge または Google Chrome で開きます）
形式 ZIP（展開して使います）。インストール不要、Python などの追加ソフトも不要です。
対応する写真 JPEG / PNG
保存形式 PNG
QRコードにできる URL http / https で始まる Web ページの URL
色 画像は sRGB を基準に処理します。
利用条件 ZIP の中の「TERMS.txt」をお読みください。
更新 新しい版はこのページからダウンロードしてください（自動更新はありません）。
